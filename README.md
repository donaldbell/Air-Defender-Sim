# Air Defender — Interactive Simulation

A standalone browser demo of **Air Defender**, a wireless, interactive air-quality arcade game built for two ESP32-based boards.

Play it here: **https://donaldbell.github.io/Air-Defender-Sim/**

This repo exists purely to host that demo page. It's a snapshot/recreation of the real hardware experience for people who want to try the game without building anything — it isn't meant to be built from or modified as source for the physical project.

For the actual hardware, firmware, and build documentation, see the main project repo: **https://github.com/donaldbell/Air-Defender**
